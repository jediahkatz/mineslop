# Bundled UI font

`Monocraft-Regular.ttf` is the unmodified regular face from [Monocraft v4.2.1](https://github.com/IdreesInc/Monocraft/releases/tag/v4.2.1) by Idrees Hassan, distributed under the SIL Open Font License 1.1.

See `Monocraft-LICENSE.txt` for the complete copyright and license. This is an independently authored Minecraft-inspired font, not a Mojang asset. The game serves it locally; no runtime font service is required.
